# 지훈 렌탈샵 — 통합 시안

## 열기

`index.html`을 브라우저에서 열면 두 시안을 선택하거나 나란히 비교할 수 있습니다. PC / 모바일 너비 전환과 단독 새 창 열기를 제공합니다.

- `index.html`: 통합 시안 비교 화면 (기본: 새 시안)
- `index1.html`: 기존 그린 컬러·일러스트 시안 보존본
- `index2.html`: 직선형 상업 사이트 스타일 시안. 요금표, 견적 계산, 강습 안내, 시즌 공지 팝업
- `assets/mountain.jpg`: 새 시안의 배경 사진. 실제 매장이나 스키장 사진이 아닌 참고 이미지

## 팝업

새 시안 진입 시 시즌 안내 팝업이 열립니다. 닫기, Escape, 오늘 하루 보지 않기를 지원합니다. '공지사항 → 내용 보기'로 다시 열 수 있습니다. 오늘 하루 보지 않기는 브라우저 로컬 저장소에 날짜를 저장합니다. 파일 직접 열기 등 저장소를 사용할 수 없는 환경에서는 닫기만 동작합니다.

## GitHub Pages

위 HTML 파일 3개와 `assets` 폴더를 같은 구조로 저장소에 업로드하세요. Pages의 배포 브랜치와 루트 디렉터리를 설정하면 통합 화면이 첫 페이지가 됩니다. 새 시안만 메인으로 사용하려면 `index2.html`을 `index.html`로 복사하고 상단·하단의 시안 비교 링크를 제거하세요. 실제 GitHub 배포는 수행하지 않았습니다.
